# Многокоординатная классификация распределённых SQL-СУБД

Статья (НИР / подача в студенческий сборник НИТУ «МИСиС»).

**Название:** «Многокоординатная классификация распределённых SQL-СУБД: построение, проверка и применение к оценке надёжности».

## О чём статья

Рыночная категория «NewSQL» не является классификационной: под неё подпадают системы с несовместимыми архитектурами, включая технологии 1990-х и документные NoSQL-СУБД, тогда как классические СУБД достигают той же распределённости средствами расширений и middleware. Взамен предлагается **многокоординатная классификация** из семи архитектурных осей (генезис распределённости, уровень её реализации, консенсус, глобальное упорядочивание транзакций, изоляция по умолчанию, движок хранения, интерфейсная совместимость).

Ключевая особенность работы — **оси не перечислены, а выведены и проверены**:

- оси выводятся из точек принятия решений эталонной архитектуры распределённой СУБД по формальной методике построения таксономий (Nickerson et al., EJIS 2013);
- выбор осей проверяется четырьмя исчислимыми тестами: релевантность (отображение осей в классы сценариев отказов), вариативность (энтропия по выборке 10 систем), воспроизводимость (все 70 значений профилей — из первичных источников), невыводимость (проверка 42 функциональных зависимостей между осями; каждая найденная выборочная зависимость разрушается реальным контрпримером: Galera, MySQL Group Replication, Oracle SERIALIZABLE, CockroachDB 23.2, MyRocks, Snowflake);
- «почему осей именно семь» — отклонённые кандидаты с номером проваленного теста + критерий краткости 7±2.

Итог — вектор-профиль системы как словарь исходных признаков для оценки надёжности (RTO/RPO/деградация) на этапе проектирования.


Файл `misisarticle.cls` должен лежать рядом с `article.tex` (шаблон: [sadekovlar/misis-article-latex](https://github.com/sadekovlar/misis-article-latex), лицензия LPPL).
