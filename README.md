# Многокоординатная классификация распределённых SQL-СУБД

Статья для сборника НИТУ «МИСиС»: XeLaTeX, две колонки, оформление классом [misisarticle](https://github.com/sadekovlar/misis-article-latex).

**Название:** «Многокоординатная классификация распределённых SQL-СУБД: признаки, проверка и применение к оценке надёжности»

## О чём статья

Рыночная категория «NewSQL» не является классификационной: под неё подпадают системы с несовместимыми архитектурами, включая технологии 1990-х и документные NoSQL-СУБД, тогда как классические СУБД достигают той же распределённости средствами расширений и middleware. Взамен предлагается **многокоординатная классификация из семи архитектурных признаков** (К1–К7): генезис распределённости, уровень её реализации, механизм консенсуса, глобальное упорядочивание транзакций, изоляция по умолчанию, движок хранения, интерфейсная совместимость.

Ключевая особенность работы — **признаки не перечислены, а выведены и проверены**:

- признаки выводятся из точек принятия решений эталонной архитектуры распределённой СУБД по методике построения таксономий (Nickerson et al., EJIS 2013);
- проверка четырьмя исчислимыми тестами: релевантность (отображение признаков в классы сценариев отказов), вариативность (энтропия по выборке 10 систем), воспроизводимость (все 70 значений профилей — из первичных источников), невыводимость (42 проверенные пары; каждая найденная выборочная зависимость разрушена реальным контрпримером: Galera, MySQL Group Replication, Oracle SERIALIZABLE, CockroachDB 23.2, MyRocks, Snowflake);
- признаки равноправны и невзвешенны; веса классам сценариев отказов назначает потребитель — методика оценки надёжности — по требованиям заказчика (RTO/RPO/деградация консистентности);
- «почему признаков именно семь» — отклонённые кандидаты с номером проваленного теста + критерий краткости 7±2.

## PDF

PDF собирается в GitHub Actions при каждом пуше: *Actions → Build → Artifacts → `article-pdf`*. В репозитории PDF не хранится.

## Сборка

```bash
# macOS: MacTeX, либо brew install tectonic
make article
# PDF: build/article.pdf

# либо прямо:
tectonic article.tex
xelatex article.tex && xelatex article.tex
```

Файл `misisarticle.cls` должен лежать рядом с `article.tex`. Компилятор — XeLaTeX (шрифт Times New Roman). В Overleaf: New Project → Upload → файлы репозитория, Compiler → XeLaTeX, главный файл — `article.tex`.
